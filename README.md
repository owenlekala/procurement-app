# TAG Procurement

Standalone Frappe app for TAG's multi-company procurement lifecycle and vendor portal.

The implementation handbook is maintained once at [docs/procurement](docs/procurement/README.md). Start with its [implementation kickoff](docs/procurement/IMPLEMENTATION_KICKOFF.md) and follow the ordered [task index](docs/procurement/tasks/README.md). The app requires ERPNext and targets the inspected Frappe/ERPNext v16 source baseline recorded in the handbook.
